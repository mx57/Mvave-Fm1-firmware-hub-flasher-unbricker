## 🎯 Главное в релизе v6.4

1. **Двуязычный интерфейс (English 🇬🇧 / Русский 🇷🇺)**:
   - В верхнюю панель (`TopAppBar`) добавлен быстрый переключатель языка интерфейса в один клик.
   - Полная локализация всех экранов приложения:
     - Навигационные вкладки: *Catalog / Каталог*, *Emulator / Эмулятор*, *Flasher / Прошивка*, *Unbricker / Восстановление*, *Backups / Бэкапы*, *Logs / Логи*.
     - Поиск и фильтры по категориям синтезаторов (*FM Synth, Groovebox, Chiptune, Virtual Analog, Ambient, Official Stock*).
     - Сортировка (*Recommended, Newest, Name A-Z, Size*).
     - Все системные подсказки, диалоги защиты загрузчика `0x00004000`, сообщения верификации контрольных сумм и статусы USB OTG.
   - Встроены полноценные ресурсы `values/strings.xml` (English по умолчанию) и `values-ru/strings.xml` (Русский).

2. **Прямая прошивка по кабелю USB OTG (аппаратно подтверждено)**:
   - Полная поддержка прошивки синтезатора M-VAVE FM-1 (SoC JieLi AC791N / WL82) прямо со смартфона через обычный OTG-кабель/переходник без моста и пайки.
   - Официальный стек команд JieLi LoaderV2:
     - Загрузка `wl82loader.bin` в системную SRAM (`0x01C02000`).
     - Аппаратная детекция и проверка доступности чипа SPI NOR Flash (`JL_CMD_LOADER_ONLINE_DEV` / `JL_CMD_LOADER_READ_ID`).
     - Безопасная очистка секторов со смещения `0x00004000` (`JL_CMD_LOADER_ERASE_SECTOR` / `0xFB01`).
     - Постраничная запись с вычислением JieLi CRC-CCITT (`JL_CMD_LOADER_WRITE_FLASH` / `0xFB04`).
     - Контрольное считывание и побайтовое сравнение (`JL_CMD_LOADER_READ_FLASH` / `0xFD05`).
     - Аппаратная перезагрузка в рабочую прошивку (`JL_CMD_LOADER_RUN_APP` / `0xFC0C`).
   - Автоматический перехват устройства после гашения экрана синтезатора без разрывов сессии и срабатывания аппаратного сторожевого таймера Watchdog.

3. **Обновленная визуальная документация и README для GitHub**:
   - Добавлены аутентичные скриншоты с реального устройства, демонстрирующие весь процесс прямой прошивки, карту секторов памяти (64 блока), статусы и живой лог USB-трассировки.
   - Полностью структурированные разделы на английском и русском языках с инструкциями по установке, шагами аварийного восстановления (Soft-Brick и Hard-Brick) и сборке проекта.
